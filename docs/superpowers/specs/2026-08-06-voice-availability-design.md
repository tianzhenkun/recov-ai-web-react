# 自定义音色停用设计

## 目标

简化音色管理的可见状态：筛选只保留“可用”和“停用”；管理员可停用并重新启用租户自定义复刻音色。停用音色不能试听、不能用于新建外呼任务。删除成功的音色不再出现在列表中。

## 范围

- 仅租户自定义复刻音色支持停用、启用和删除。
- 内置音色始终可用，不能被当前租户停用或删除。
- 性别筛选移除“未知”；不改变历史或创建请求中已有的性别数据。
- 不改变创建、删除的异步任务机制。

## 状态与业务规则

| 持久状态 | 管理页展示 | 可执行操作 |
| --- | --- | --- |
| `ENABLED` | 可用 | 试听、停用、删除 |
| `DISABLED` | 停用 | 启用、删除 |
| `CREATING`、`CREATE_FAILED` | 保留真实状态 | 无可用性切换 |
| `DELETING`、`DELETE_FAILED` | 保留真实状态 | 删除失败时可重试删除 |
| `DELETED` | 不展示 | 无 |

- 停用/启用只允许在 `ENABLED` 和 `DISABLED` 间切换。
- 异步删除成功后状态为 `DELETED`，默认列表和筛选均不展示。
- 删除中和删除失败不能被提前隐藏；否则异步删除失败时管理员没有可恢复入口。
- 新建任务的音色选项只查询 `availableOnly=true`，后端也必须拒绝任何非 `ENABLED` 的租户音色。

## 接口与数据

- 在现有租户音色状态枚举中加入 `DISABLED`。
- 增加仅面向租户音色的状态切换接口，接收目标状态 `ENABLED` 或 `DISABLED`。
- 音色列表状态筛选仅暴露 `ENABLED` 和 `DISABLED`，已删除记录始终以 `includeDeleted=false` 查询。
- 删除校验和删除请求同时支持 `ENABLED`、`DISABLED` 的自定义音色。
- 内置音色调用状态切换接口必须返回无权限或不可操作错误，不能修改全局数据。

## 前端交互

- “性别”筛选项仅保留女声、男声。
- “状态”筛选项仅保留可用、停用。
- 可用的自定义音色显示“停用”；停用的自定义音色显示“启用”。
- 停用音色不显示试听入口；启用后恢复试听和新建任务可选性。
- 删除仍使用现有二次确认和异步轮询；轮询得到 `DELETED` 后刷新列表并移除该行。

## 异常与重试

- 状态切换遇到并发变更、删除中、创建中或状态不合法时，后端返回冲突，前端提示后刷新列表。
- 音色仍被运行中任务引用时，删除继续沿用现有阻止逻辑。
- 删除失败保留行与失败原因，可从“删除”再次发起删除；不新增自动重试。

## 验证

- 前端：筛选不再显示“未知”及创建/删除过程状态；自定义音色可停用、启用；内置音色无切换操作；删除成功后列表移除。
- 前端：创建任务选项不包含 `DISABLED`，并保持 `availableOnly=true` 请求。
- 后端：状态切换、禁止修改内置音色、删除停用音色、非 `ENABLED` 音色创建任务被拒绝。
